Design options

Option C was chosen and is now live at the main calculator, with per-model overrides added so mixed sites can still be described. These three previews are kept for reference and are no longer maintained.

Three takes on a cleaner bandwidth calculator. Same validated model in all three — only the interface differs. Open each on your phone as well as desktop.

Option A

Blueprint

Editorial technical. Warm paper, hairline rules, serif numerals. The uplink figure lives in a sticky side rail so it never leaves the screen while you configure. Per-model feature chips.

light · Fraunces + Karla · every control visible at once
 Option B

Console

Dark instrument panel. Live telemetry pinned to the top bar. Nine columns instead of sixteen — AI features collapse into one cell per row that expands on demand.

dark · Martian Mono + Archivo · densest, fastest to scan
 Option C

Steps

One decision at a time, three cards. Search-to-filter model picker, site-wide archiving switch, big tap targets. Copy-summary button for dropping numbers into an email from site.

light · Instrument Serif + Figtree · phone-first
